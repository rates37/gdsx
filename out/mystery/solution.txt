How to drive it
  1. one clock with rst_n = 0 and enable = 1
     (enable matters even during reset: four flops have no reset of their own)
  2. rst_n = 1, enable = 1, then feed I one bit per rising clock, first bit first:

     0000000101010000100000000000010101010000000000001010000001000
     001000000100000101000010000000100000010000010010001010000000

     121 bits
  3. one further clock -- success is a registered flag, so it appears the
     cycle after the last key bit (that cycle's I value is irrelevant)

verified by simulating the extracted netlist: success = 1, O = 00101000 = 0x28
key truncated by one bit           -> success = False
single-bit corruptions (13 sampled) -> 0 still succeed
